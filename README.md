# Курс для Саши

Это репозиторий курса, собранного специально для тебя.

## Как устроены папки

Курс идёт блоками. У каждого блока своя папка: `block-1-...`, затем `block-2-...` и дальше по ходу курса.

Внутри блока лежат недели: `week-1`, `week-2` и так далее.

Внутри недели две папки:

- `materials` — конспекты и ссылки на то, что проходим на этой неделе
- `practice` — сюда кладётся домашка

## Как сдавать домашку

Домашку не клади в основную ветку. Сделай отдельную ветку — копию основной — и прикрепи файл в папку `practice` нужной недели. Основная ветка остаётся общей и чистой, твоя сдача живёт в своей ветке.

## Как читать конспекты

Заметки написаны в Markdown. Скачай [Obsidian](https://obsidian.md/) и открой в нём папку этого репозитория: там конспекты выглядят куда красивее и читабельнее, чем сырой текст.
