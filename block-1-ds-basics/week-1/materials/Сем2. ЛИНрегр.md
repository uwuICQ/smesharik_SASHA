## Аналитическое решение

$$\mathbf{w}=(X^\top X)^{-1}X^\top\mathbf{y}$$

Единицу дописывают столбцом справа, не слева. Тогда последний вес — свободный член. `np.linalg.inv` падает, если $X^\top X$ вырождена.

```python
class MyLinearRegression:
    def __init__(self):
        self.w = None

    def fit(self, X, y):
        X = np.array(X)
        y = np.array(y)[:, np.newaxis]
        l, n = X.shape
        X_train = np.hstack((X, np.ones((l, 1))))
        self.w = np.linalg.inv(X_train.T @ X_train) @ X_train.T @ y
        return self

    def predict(self, X):
        l, n = X.shape
        X_train = np.hstack((X, np.ones((l, 1))))
        return X_train @ self.w

    def get_weights(self):
        return self.w.copy()
```
*`@` — знак матричного умножения в Python*

> [!tip] Тезис
> `get_weights` возвращает копию. Без `copy` снаружи можно случайно переписать `self.w`.

На этих точках прямая совпадает с `sklearn.linear_model.LinearRegression`: у sklearn ==вес признака лежит в `coef_`, свободный член отдельно в `intercept_`==. Качество смотрят через `mean_squared_error` на train и на test.

## Градиентный спуск

Формула есть не у всякого лосса. Дальше минимум ищут шагами. Градиент MSE:

$$\frac{\partial L}{\partial\mathbf{w}}=\frac{2}{\ell}X^\top(X\mathbf{w}-\mathbf{y})$$

```python
class MyGradientLinearRegression(MyLinearRegression):
    def fit(self, X, y, lr=0.01, max_iter=100):
        y = np.array(y)[:, np.newaxis]
        l, n = X.shape
        X_train = np.hstack((X, np.ones((l, 1))))
        self.w = np.random.randn(n + 1, 1)
        self.losses = []
        for _ in range(max_iter):
            y_pred = self.predict(X)
            self.losses.append(mean_squared_error(y, y_pred))
            grad = (2.0 / X_train.shape[0]) * (X_train.T @ (y_pred - y))
            self.w -= lr * grad
        return self
```

Стартовые веса случайные. На графике лосса по итерациям видно, сошёлся ли шаг. Маленький `lr` почти не двигает линию за 100 шагов, слишком большой разбрасывает веса.

## Стохастический градиентный спуск

Градиент по всем строкам на каждом шаге дорог. SGD считает его по случайным $k$ объектам. В ноутбуке два способа выбрать батч. На занятии берут случайную подвыборку без возвращения. Второй способ — генератор, который помнит место в данных через `yield`; 

```python
class MySGDLinearRegression(MyGradientLinearRegression):
    def __init__(self, n_sample=10, **kwargs):
        super().__init__(**kwargs)
        self.n_sample = n_sample

    def _calc_gradient(self, X, y, y_pred):
        inds = np.random.choice(np.arange(X.shape[0]), size=self.n_sample, replace=False)
        return 2 / self.n_sample * X[inds].T @ (y_pred[inds] - y[inds])
```

На размерах батча 1, 4 и 16 при `lr=5e-3` и 150 итерациях лосс доходит примерно до одного уровня, но кривая при батче 1 дёргается сильнее. Чем меньше батч, тем шумнее шаг. Адаптивное уменьшение шага ноутбук откладывает на курсы по оптимизации. Подробнее, чем батч отличается от эпохи, — в [[Лекция 2. ДОП ШАД#Батч и эпоха|дополнении из ШАД]].
