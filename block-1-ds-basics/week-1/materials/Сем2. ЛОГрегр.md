# Семинар 2. Логистическая регрессия

Свой класс бинарного классификатора и градиентный спуск по LogLoss. Теория — [[Лекция 2. Линейные модели#Логистическая регрессия|лекция]]. Выход до сигмоиды — логит. После сигмоиды — вероятность класса 1.

Видео: [YouTube](https://www.youtube.com/watch?v=aGtbbiPCHdE)
Ноутбук: [part_3_logistic_regression.ipynb](https://github.com/DeepLearningSchool/part_1_ml_cv/blob/autumn26/week_02_linear_models/Practice/part_3_logistic_regression.ipynb)

$$\sigma(t)=\frac{1}{1+e^{-t}},\qquad y_{pred}=\sigma(\langle\mathbf{x},\mathbf{w}\rangle)$$
![[Pasted image 20261006234956.png]]
Лосс одного объекта:

$$L=-y\log y_{pred}-(1-y)\log(1-y_{pred})$$

Цепное правило кажется длинным, но производная сигмоиды $\sigma(t)(1-\sigma(t))$ сокращается с множителем из логарифмов. На одном объекте остаётся $(y_{pred}-y)\,\mathbf{x}$. На всей матрице:

$$\frac{\partial L}{\partial\mathbf{w}}=\frac{1}{\ell}X^\top(\mathbf{y}_{pred}-\mathbf{y})$$

```python
class MyLogisticRegression:
    def sigmoid(self, t):
        return 1. / (1 + np.exp(-t))

    def grad(self, X, y_true, y_pred):
        return X.T @ (y_pred - y_true) / X.shape[0]

    def loss(self, y, y_pred):
        return np.mean(-y * np.log(y_pred) - (1 - y) * np.log(1 - y_pred))

    def fit(self, X, y, max_iter=100, lr=0.1):
        y = np.array(y)[:, np.newaxis]
        l, n = np.array(X).shape
        X = np.hstack([np.ones([l, 1]), X])
        weights = np.random.randn(n + 1, 1)
        losses = []
        for _ in range(max_iter):
            y_pred = self.sigmoid(X @ weights)
            weights -= lr * self.grad(X, y, y_pred)
            losses.append(self.loss(y, y_pred))
        self.coef_ = weights[1:]
        self.intercept_ = weights[0]
        return losses
```

```python
def predict_proba(self, X):
    l, n = np.array(X).shape
    X = np.hstack([np.ones([l, 1]), X])
    
    prob_class_1 = self.sigmoid(X @ self.weights) # Форма (l, 1)
    prob_class_0 = 1 - prob_class_1 
    return np.hstack([prob_class_0, prob_class_1]) # Форма (l, 2)

```

`predict_proba` возвращает сигмоиду. `predict` в ноутбуке режет вероятность порогом 0.5 и выдаёт метку. Для [[Лекция 1.
