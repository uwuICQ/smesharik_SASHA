# Семинар 2. Регуляризация линейной регрессии

$L_1$, $L_2$ и зачем штрафовать веса. Теория — [[Лекция 2. Линейные модели#Регуляризация|лекция]]. Свободный член в штраф не входит: это сдвиг, а не сложность.

Видео: [YouTube](https://www.youtube.com/watch?v=xzkfLfb5OMQ)
Ноутбук: [part_2_regularization.ipynb](https://github.com/DeepLearningSchool/part_1_ml_cv/blob/autumn26/week_02_linear_models/Practice/part_2_regularization.ipynb)

$$L(\mathbf{w})=\frac{1}{\ell}\sum_i(\langle\mathbf{w},\mathbf{x}^i\rangle-y^i)^2+R(\tilde{\mathbf{w}})$$

$\tilde{\mathbf{w}}$ — веса без свободного члена.

|              | штраф                | что делает с весами                      |
| ------------ | -------------------- | ---------------------------------------- |
| Lasso, $L_1$ | $\lambda\sum\|w_j\|$ | часть весов становится нулём             |
| Ridge, $L_2$ | $\lambda\sum w_j^2$  | веса уменьшаются, нулями не становятся   |
| ElasticNet   | смесь обоих          | и то и другое, на семинаре только назван |

## Lasso своими руками

Градиент MSE плюс знак весов. В нуле модуль не дифференцируем. ==🟡`soft_sign`== в маленькой окрестности нуля возвращает $x/\varepsilon$, чтобы шаг не прыгал.

![[Pasted image 20261007000010.png|540]]

$$\frac{\partial L}{\partial\mathbf{w}}=\frac{2}{\ell}X^\top(X\mathbf{w}-\mathbf{y})+\lambda\,(0,\mathrm{sign}(w_1),\ldots,\mathrm{sign}(w_n))^\top$$

Шаг затухает: `lr / sqrt(iter + 1)`. В sklearn тот же коэффициент называется `alpha`, в классе ноутбука — `C`.
![[Pasted image 20261007000737.png|505]]

```python
def soft_sign(x, eps=1e-7):
    if abs(x) > eps:
        return np.sign(x)
    return x / eps

class MyLassoRegression:
    def __init__(self, C=1):
        self.C = C

    def grad(self, X, y, weights):
        basic = 2 / X.shape[0] * X.T @ (X @ weights - y)
        signs = np_soft_sign(weights)
        signs[0] = 0
        return basic + self.C * signs
```

`fit` дописывает столбец единиц слева, инициализирует веса случайно и на каждом шаге вычитает градиент. `coef_` — все веса кроме первого, `intercept_` — первый. Проверка на прямой $5x+6$ с шумом: линия должна сесть рядом с зелёной, лосс по итерациям — упасть.

scaler = StandardScaler()

> [!warning] Важно
> `fit` скейлера только на train. Иначе среднее и дисперсия test попадут в обучение. Это та же утечка, что в [[Сем1. Pandas, Matplotlib#Train/test и масштабирование|первом семинаре]]. Без общей шкалы Lasso и Ridge штрафуют не сложность, а единицы измерения.

Дальше `MyLassoRegression(C=0.001)` на нормированных признаках. Столбчатая диаграмма `coef_` показывает, какие признаки выжили. MSE считают `mean_squared_error` отдельно на train и test.

Если прогнать сетку `C` и нарисовать вес каждого признака против $C$, траектории Lasso доходят до нуля и остаются там. У `sklearn.linear_model.Lasso` картинка та же, только `alpha` и аналитический солвер, не градиент из ноутбука.

## Ridge

Штраф — сумма квадратов, градиент штрафа — сам вес, снова без свободного члена:

$$\frac{\partial L}{\partial\mathbf{w}}=\frac{2}{\ell}X^\top(X\mathbf{w}-\mathbf{y})+2\lambda\,(0,w_1,\ldots,w_n)^\top$$

Класс `MyRidgeRegression` в ноутбуке уже содержит этот градиент. В строке лосса внутри `fit` стоит `np.abs`, как у Lasso. Для графика ошибки Ridge там нужна сумма квадратов, не модулей. Сравнение кривых весов на семинаре делают через `sklearn.linear_model.Ridge`: при росте `C` веса сжимаются к нулю плавно и не обнуляются пачкой.

> [!tip] Тезис
> Lasso труднее учить: закрытой формулы нет, зато нулевые веса выкидывают признак. Ridge формулу имеет и нули почти не ставит. Оба требуют нормировки, иначе штраф несравним между колонками.
